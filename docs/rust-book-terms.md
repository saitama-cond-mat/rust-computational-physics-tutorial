# Rust Book公式用語表

この表は、公式の [The Rust Programming Language 日本語版](https://doc.rust-jp.rs/book-ja/)
と英語版 [The Rust Programming Language](https://doc.rust-lang.org/stable/book/)
を照合して作成したRust用語表です。

教材本文では、独自訳を作らず、原則としてこの表の訳語を使います。
表にない語を使う場合は、公式日本語版を確認してから追加します。

注意:

- 日本語版は提供ページ上で Rust 1.58 以降前提です。
- 英語 stable 版はより新しいため、日本語版にない章や語があります。
- `function boundary`、`function boundaries`、`関数境界`、`関数の境界` は、
  日英Rust Book全文では確認できませんでした。
  型・ライフタイム・API境界の話では `関数シグニチャ`、
  入出力の説明では `関数の引数と戻り値` を使います。
